# Satış Bölgeleri Haritası

Laciel Paris için prototip: il, ilçe, semt ve mahalle seçip **Satış İzin** (yeşil) / **Satış Red** (kırmızı) olarak işaretleme haritası.

İşaretler, haritanın açıldığı tarayıcıda saklanır.

Harita verisi: il/ilçe sınırları geoBoundaries; mahalle ve semtler © OpenStreetMap katkıcıları (ODbL).
